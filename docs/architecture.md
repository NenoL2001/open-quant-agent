# Architecture

Open Quant Agent is a local, safe-by-default research loop. It does not execute arbitrary code generated by a model. Factor ideas are represented as structured dataclasses and traditional factors compile through a bounded feature DSL.

## Modules

| Module | Responsibility |
| --- | --- |
| `schemas.py` | Shared dataclasses for ideas, debate reports, factor validations, strategy specs, records, and state. |
| `agents.py` | Research, debate, implementation, factor validation, and supervisor agents. |
| `feature_dsl.py` | Safe math feature expression compiler and cross-sectional panel builder. |
| `dl_factors.py` | Optional PyTorch LSTM, Transformer, and Temporal Fusion Lite factor generators. |
| `hybrid_factors.py` | Factor panel evaluation and factor fusion. |
| `strategy_agents.py` | Strategy construction, portfolio backtesting, and strategy promotion. |
| `data.py` | yfinance download helpers, default universe, and deterministic synthetic data. |
| `memory.py` | JSONL, checkpoint, state, and Markdown memory writers. |
| `orchestrator.py` | End-to-end loop coordinator. |
| `cli.py` | Command line entrypoint. |

## Data Modes

Offline mode uses deterministic synthetic OHLCV data. It is intended for smoke testing and CI.

Online mode uses yfinance and the built-in liquid US stock and ETF universe.

## Promotion Boundary

Factors and strategies are promoted separately:

1. A factor can be `accepted` based on IC, OOS rank IC, spread, Sharpe, drawdown, and coverage.
2. A strategy can be `accepted` only after portfolio-level backtesting.
3. Strategy acceptance requires positive OOS excess versus an equal-weight benchmark, not just high absolute return.
